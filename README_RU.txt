САЙТ «ПРОСТИ МЕНЯ МОЯ АЙДУНЯ»

1. Распакуй ZIP.
2. Открой index.html в браузере (двойной клик).
3. В архив уже добавлены 6 фотографий. Чтобы их заменить, скопируй 6 своих изображений в папку assets/photos.
   Назови их photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg, photo6.jpg.
   На каждой из трёх страниц будет по 2 фото.
4. Чтобы изменить надписи и письмо, открой config.js в любом текстовом редакторе.
   Там есть introWords, pages, letterTitle, letter, signature.
   Сохрани и обнови страницу.
5. Чтобы отправить сайт ссылкой, загрузи всю ПАПКУ на Netlify Drop (https://app.netlify.com/drop)
   или другой статический хостинг. Отдельно загружать index.html недостаточно.

РЕКОМЕНДАЦИИ
Фотографии лучше вертикальные. Формат JPG, размер около 1000-1600px по длинной стороне.
Сайт адаптирован для мобильных устройств, поддерживает свайпы и стрелки на клавиатуре.
При наличии интернета загрузятся красивые шрифты Google Fonts, без интернета браузер покажет запасные.

ENGLISH
Unzip, open index.html, add six photos to assets/photos named photo1.jpg through photo6.jpg.
Edit messages in config.js. Upload the entire folder to Netlify Drop for a shareable URL.

ОБНОВЛЕНИЕ 2
1. После отсчёта и слов появляется отдельный экран с кнопкой «Включить музыку». На телефонах музыка запускается именно после нажатия, как требуют браузеры.
2. Встроенная мелодия: assets/music/romantic-melody.mp3. Можно заменить своим файлом, оставив то же имя, либо поменять src в index.html. Музыку можно включать/выключать кнопкой ♪ сверху справа.
3. Три главы перелистываются влево и вправо свайпом по экрану, стрелками либо точками. Переход выполняется с 3D эффектом книжной страницы.
4. Текст над двумя фото мягко проявляется по словам примерно за 5 секунд. Свайп не нужно ждать до конца печати.
5. Финальное письмо плавно раскрывается по словам. Скорость настраивается параметром letterWordDelay в config.js (миллисекунды, меньше значит быстрее).
6. Для отправки девушке ссылкой разместите все файлы папки на хостинге статических сайтов (например, Netlify Drop). Просто ZIP в мессенджере не является веб-ссылкой.

ОБНОВЛЕНИЕ: плавное появление вступительных надписей, текста на страницах и письма; мягкое открытие конверта и перелистывание.
